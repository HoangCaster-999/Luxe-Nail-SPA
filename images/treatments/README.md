# Treatment image audit

All 23 price-list entries and all six Popular Services were checked individually. The price list uses 23 distinct image files. A Popular Service may reuse the illustration of that same treatment from the price list.

Fourteen new treatment illustrations were created with the built-in Imagegen tool. They are illustrative images, not photographs of work performed by this salon, and are not included in the salon Gallery. The Gallery retains the owner's 14 real salon photographs.

Each generated image is exported as a square JPEG for web use. Complete generation prompts are recorded in `prompts.json`.
